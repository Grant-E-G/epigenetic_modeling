# Baselines and novelty boundary

See [the literature review](../../notes/reading_list.md) for verified references and mechanism evidence.

- **Executed:** published processed Polycomb age mean/SD/skew summaries; one-state versus slow/fast switching distribution comparison with leave-one-mouse-out prediction. Continuous exponential switch quadrature and Gaussian weekly gain approximation replace the unavailable MATLAB helper. This is an independent approximate baseline, not exact reproduction of the published optimizer.
- **Executed:** whole-matrix longitudinal M0 endpoint summaries, then M1 versus constant young reference on fixed outcome-independent probe subsets, with leave-one-donor/person-out evaluation.
- **Executed:** external ESL/sequence/platform feature import and exploratory F2/F8 matched-mask tests on the full human matrices, with donor-level effect summaries. This validates neither functional essentiality nor a causal protection coefficient.
- **Executed:** pure protection, pure selection and combined simulations; matched survivor endpoint probabilities demonstrate one-snapshot non-identifiability.
- **Implemented and numerically tested, not validated on these real datasets:** M2 hierarchical context/constraint rate fit; M3 survivor-normalized particle likelihood; M4a/M4b/M5 simulation/particle likelihood, low-rank residual factors; matched masks and first passage.
- **Not reproduced:** Tong stochastic clocks, Dabrowski acceleration/bias inference, Fu strand-paired fidelity inference, or a held-out essentiality/identity constraint analysis. Cite them as prior art, not as replicated benchmarks.

The candidate contribution remains explicit protection-versus-selection comparison using external functional scores and independent identity validation. No novelty claim is established by this run. In particular hierarchical fidelity inference, stochastic clocks, latent switching and epigenetic-memory first passage all have prior work.
