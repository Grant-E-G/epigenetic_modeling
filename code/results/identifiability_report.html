Binary observations, binomial/beta-binomial read counts with fixed dispersion, and noisy aggregate arrays all have the same likelihood when endpoint probability is matched. This equivalence does not assert that realistic multisite longitudinal data are always unidentifiable. Observed disappearance or clone representation and generation-time methylation can help, but those require an expanded observation model.
